# Verdan — ED Treatment Quiz Funnel

Production-quality mobile-first funnel for **Khalil / client review**. Keeps-level craft; original brand (not Keeps or MEDVi).

## Brand

- **Verdan** — *Confidence backed by modern care.*
- Palette: forest · ivory · sage · copper — see [BRAND.md](./BRAND.md) and [CLIENT_DELIVERABLE.md](./CLIENT_DELIVERABLE.md)

## Five screens

1. **Hero** — Typography, layered media, entrance animation, trust  
2. **Quiz** — Single/multi-select, age slider, card UI, micro-interactions  
3. **Interstitial** — Stats, timeline, dark/light rhythm  
4. **Results reveal** — Sequenced loading → insights → plan  
5. **Recommendation** — Product, pricing, sticky CTA  

## Run

```bash
cd verdan-quiz
npm install
npm run dev
```

http://localhost:5173 — best at **390px** width.

```bash
npm run build
npm run preview
```

## Stack

React 19 · Vite 8 · Tailwind CSS v4 · Framer Motion 12
